# Mes ordinateurs

Le catalogue de toutes mes machines. Il est **partagé** : n'importe quel Claude, sur
n'importe quel poste, peut le lire pour savoir où vit tel projet ou tel outil.

Le poste où tu tournes **maintenant** est indiqué dans `machines.md` (chargé au démarrage),
pas ici. Ne les confonds pas : ce fichier dit ce qui existe sur l'ensemble de mes postes,
`machines.md` dit sur lequel tu te trouves.

---

## Le modèle à suivre par machine

```markdown
## <nom exact donné par hostname>

- Système : (ex. Linux Mint 22, Ubuntu, Windows…)
- Rôle habituel : (ex. PC principal, portable de déplacement, station de calcul…)
- Ce qui n'existe que sur cette machine : (dossiers non poussés sur GitHub, GPU, simulateur, données lourdes…)
```
